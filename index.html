Ce qu'il faut ramener de la salle

La jauge

Sur un créneau de midi en semaine de haut niveau, une confirmation sur deux se transforme en présence. Visez trois invitations pour une place, suivez l'écart chaque jour.

La tribune

Huit places, dans l'ordre de placement proposé. Cochez quand la personne est confirmée, que son badge est sécurisé et que sa fiche est arrivée : nom et titre exacts, photo carrée d'au moins 1000 px, biographie de 60 à 80 mots, message en deux ou trois phrases, besoins techniques. Chaque siège a un suppléant désigné.

À convier

Liste de travail du dossier maître, augmentée du statut d'accès au Siège. C'est ce statut, et non l'intérêt pour le sujet, qui détermine qui sera physiquement dans la salle.

Les bilatérales

Un événement parallèle ne décide pas d'un financement : il légitime une demande déjà posée. Les rendez-vous en marge sont l'endroit où l'argent se discute. À caler avant le départ, pas sur place.

Recueillir les engagements

Une annonce non écrite disparaît en trois jours. Chaque partenaire qui s'exprime repart avec une fiche d'une page à renseigner sur place : institution, nature de l'appui, ordre de grandeur, échéance, point de contact.

Après l'événement

La redevabilité se joue dans les trente jours. Passé ce délai, les annonces faites en salle ne se rattrapent plus.

Voir le script à coller (memoire-partagee.gs) 
function feuille(){
  var f = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Etat');
  if(!f){ f = SpreadsheetApp.getActiveSpreadsheet().insertSheet('Etat');
          f.appendRow(['id','valeur','auteur','horodatage']); }
  return f;
}
function doGet(){
  var d = feuille().getDataRange().getValues(); d.shift();
  var out = d.map(function(l){ return {id:l[0], v:l[1], by:l[2], at:l[3]}; });
  return ContentService.createTextOutput(JSON.stringify(out))
         .setMimeType(ContentService.MimeType.JSON);
}
function doPost(e){
  var r = JSON.parse(e.postData.contents);
  var f = feuille(), d = f.getDataRange().getValues(), trouve = 0;
  for(var i=1;i<d.length;i++){ if(d[i][0]===r.id){ trouve = i+1; break; } }
  if(trouve){ f.getRange(trouve,1,1,4).setValues([[r.id,r.v,r.by,r.at]]); }
  else { f.appendRow([r.id,r.v,r.by,r.at]); }
  return ContentService.createTextOutput(JSON.stringify({ok:true}))
         .setMimeType(ContentService.MimeType.JSON);
}

Modifier, ajouter, attribuer

Le crayon à droite de chaque activité ouvre un formulaire : intitulé, échéance et responsable, modifiables sur toutes les activités, y compris celles du dossier maître. La valeur d'origine reste rappelée sous le formulaire et se rétablit d'un bouton : rien n'est jamais écrasé définitivement. Une activité modifiée porte la mention « modifiée ».

En bas de chaque rubrique, « Ajouter une activité ou une sous-tâche » crée une nouvelle ligne, avec rattachement facultatif à une activité existante. Ces ajouts portent la mention « ajoutée » et sont, eux, supprimables.

Pour attribuer, touchez la pastille du nom. Le panneau qui s'ouvre liste les personnes connues et permet d'en créer une nouvelle, avec son rattachement ; elle devient aussitôt disponible pour tout le monde et sur toutes les activités.

Modifications, ajouts, personnes et compteurs passent par le même classeur que les coches, sous des identifiants préfixés edit:, task:, resp:, role: et num:. Ces lignes apparaissent dans l'onglet Etat : ne les supprimez pas.

Ce que la page fait toute seule

Elle relit la mémoire partagée toutes les vingt secondes et à chaque retour sur l'onglet. Elle bascule sur « Jour J » le 23 septembre au matin. Si le réseau tombe, elle continue de fonctionner sur les dernières valeurs connues et renvoie vos coches dès qu'il revient. Le bouton Imprimer sort la totalité des onglets en un document, pour la réunion de comité.
