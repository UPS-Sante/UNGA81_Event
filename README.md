# La foi en action — préparation de l'événement parallèle UNGA 81

Site de préparation interne du MSPP pour l'événement parallèle de haut niveau
« La foi en action », New York, mardi 23 septembre 2026, 13 h 15 à 14 h 45.

Organisé par le Ministère de la Santé Publique et de la Prévention avec le CNAIT,
la Ligue des Femmes Prédicatrices et l'UNFPA, sous le Haut Patronage du Ministre
de la Santé Publique et de la Prévention.

## Contenu

- `index.html` : page unique, sans dépendance, fonctionne hors connexion.

## Utilisation

Ouvrir `index.html` dans un navigateur, ou le servir par GitHub Pages.

Chaque membre de l'équipe renseigne son nom dans l'onglet Réglages. Sans mémoire
partagée, les coches restent sur l'appareil. Pour que toute l'équipe voie les
mêmes cases, créer un Google Sheet, y coller le script Apps Script fourni dans
l'onglet Réglages, déployer en application web accessible à tous, puis coller
l'adresse se terminant par `/exec` dans le champ prévu.

## Onglets

Préparer, Jour J, Invités, Suivi, Repères, Historique, Réglages.

L'onglet Repères porte les éléments confrontés aux sources officielles des
Nations Unies, avec leur source et leur date de consultation. Les points qui
contredisent le dossier maître du 3 septembre 2026 y sont signalés.

Document de travail interne.
